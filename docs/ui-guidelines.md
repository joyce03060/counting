# 记账app — 界面设计规范

## UI 风格方向（待选择）

将向用户展示以下风格方向供选择：

### 方向 A：极简单色风

- 特点：大面积留白、单一主题色、极简线条
- 参考：微信记账、iOS 原生风格
- 适合：追求简洁、不喜欢复杂界面的用户

### 方向 B：温暖卡片风

- 特点：圆角卡片、柔和色彩、渐变背景、生活化图标
- 参考：鲨鱼记账、随手记
- 适合：喜欢温馨、有生活气息的界面风格

### 方向 C：专业数据风

- 特点：深色模式为主、数据仪表盘、专业图表、信息密度高
- 参考：MoneyWiz、Expensify
- 适合：喜欢数据分析、需要查看详细报表的用户

---

## 设计原则（已确定）

1. **操作简单**：主要操作不超过 3 步完成
2. **点击优先**：能用点击选择的绝不让用户打字
3. **反馈清晰**：每次操作都有明确的视觉反馈
4. **跨平台一致**：Windows 和 Mac 上布局和交互保持一致
5. **中文优先**：所有界面文字使用中文
6. **无障碍友好**：字体大小适中，按钮触控区域足够大
