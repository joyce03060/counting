# 记账app — 费用分类体系

## 设计说明

本分类体系覆盖日常生活的各个方面，共设计 **10 个一级大类** 和 **45 个二级小类**。分类参考了主流记账应用的实践经验，并针对中国用户的消费习惯做了优化。

分类采用两级级联结构：用户先选择一级大类，再在弹出的二级小类列表中选择具体分类。

## 分类使用说明

1. **两级级联选择**：用户先看到 10 个一级大类的列表，点击某个大类后，自动展开对应的二级小类供选择

2. **默认分类**：如果用户没有特别选择，系统默认选择「其他杂项 → 其他」

3. **快速选择**：系统记住用户最近常用的 5 个分类，在记账时优先展示，减少选择时间

4. **分类扩展**：后续版本支持用户自定义添加/修改分类（MVP 版本使用预设分类）
