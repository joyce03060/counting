# 前端代码规范

> 本规范适用于 `src/renderer/`、`src/components/`、`src/pages/` 等界面相关代码。

---

## 组件编写规范

1. 每个组件一个文件，文件名使用 kebab-case（如 `expense-form.tsx`、`category-picker.tsx`）

2. 组件结构顺序：
   - 类型定义
   - 组件函数
   - 样式（如使用 CSS-in-JS）

3. 使用函数组件 + Hooks，不使用类组件

4. 表单组件必须包含以下状态处理：
   - 加载中
   - 空数据
   - 错误
   - 成功

---

## 样式规范

1. 优先使用 CSS Modules 或 Tailwind CSS（待用户选定）

2. 颜色和间距使用设计规范中定义的变量，不直接写死数值

3. 所有可点击元素必须有 hover 和 active 状态

4. 金额数字统一使用等宽字体（monospace），方便对齐阅读

---

## 交互规范

1. 按钮点击后如果涉及数据处理，需显示加载状态防止重复点击

2. 删除操作必须有确认步骤

3. 表单提交成功后显示简短的成功提示

4. 金额输入框自动处理小数点，只允许两位小数
