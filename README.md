# 记账app

一款简洁好用的跨平台桌面记账应用，帮你轻松记录每一笔花销。

---

## ✨ 功能特点

- **📝 快速记账** — 选择分类、输入金额，几秒钟完成一笔记账
- **📂 两级分类** — 10 大类 + 45 小类，覆盖日常所有消费场景
- **📊 月度统计** — 饼图直观展示每月各分类支出占比
- **📋 今日清单** — 按时间倒序展示当天所有记录
- **📤 CSV 导出** — 一键导出数据，可用 WPS / Excel 打开查看
- **⚙️ 自定义分类** — 自由添加或修改消费分类，更贴合个人习惯
- **🔒 隐私安全** — 所有数据只存在你电脑上，不上传任何服务器
- **🌐 离线可用** — 不需要网络，随时随地打开就用

## 📸 界面预览

应用包含三个主要页面：

1. **记账页** — 选分类、填金额、记一笔
2. **统计页** — 看本月的消费饼图和汇总
3. **设置页** — 管理自定义分类

## 🚀 安装和运行

### 下载安装（推荐）

> 前往 [Releases](../../releases) 页面，下载适合你系统的安装包：
> - Windows 用户下载 `.msi` 或 `.exe` 文件
> - Mac 用户下载 `.dmg` 文件

双击安装即可使用。

### 开发者运行

如果你熟悉编程，也可以从源代码运行：

```bash
# 1. 克隆项目
git clone https://github.com/wangsiran/heimajizhang.git
cd heimajizhang

# 2. 安装依赖
npm install

# 3. 启动开发模式
npm run tauri dev
```

## 📦 费用分类

应用内置了 10 个一级大类，涵盖日常生活的方方面面：

| 分类 | 包含 |
|------|------|
| 🍜 餐饮美食 | 三餐、外卖、买菜、零食、聚餐 |
| 🏠 住房居住 | 房贷房租、水电燃气、物业、宽带、维修 |
| 🚗 交通出行 | 公交、打车、加油、停车、养车 |
| 🛒 购物消费 | 服饰、个护、数码、家居、日用 |
| 💊 医疗健康 | 看病、药品、住院、保健、健身 |
| 📚 教育学习 | 培训、书籍、考试 |
| 🎮 休闲娱乐 | 影视、游戏、旅游、聚会 |
| 🎁 人情往来 | 红包、礼物、孝敬长辈、捐款 |
| 💰 金融保险 | 保险、贷款利息、税费 |
| 📦 其他杂项 | 宠物、快递、其他 |

除了预设分类，你也可以在「设置」页面自由添加自己的分类。
